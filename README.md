# Транспортная задача (метод северо-западного угла + МОДИ)

## Описание
Веб-приложение для решения транспортной задачи. Позволяет загрузить данные в формате JSON, пошагово просматривать итерации метода потенциалов и получить оптимальный план перевозок.

## Установка и запуск
### Локально
1. Установить Python 3.10+
2. `pip install -r requirements.txt`
3. `python src/app.py`

### Docker
1. `docker build -t transport_app .`
2. `docker run -p 5000:5000 transport_app`

## Использование
- Откройте браузер по адресу http://localhost:5000
- Загрузите JSON-файл с данными (пример в `data/example.json`)
- Нажмите "Рассчитать"
- Просмотрите пошаговые результаты

## Тестирование
`pytest tests/`
